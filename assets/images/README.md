# SUDONPO Image Naming Guide

Use these exact file names. Replace image files with the same names to update the website without editing HTML/CSS.


## Dark Chapel (chapel.html)
- chapel-hero.jpg
- chapel-ritual-hall.jpg
- chapel-priest-vesper.jpg
- chapel-priest-eidolon.jpg
- chapel-priest-ruin.jpg
- chapel-vow.jpg

## Notes
- Recommended format: JPG.
- Recommended minimum width:
  - hero images: 1920px
  - card images: 800px
  - profile images: 600px
- Keep the same filename and extension.
